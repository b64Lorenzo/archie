Help - How to Use Archie

📂 Scanning Directories

Home Page (Start): When you first open Archie, you'll see a clean screen with a large folder icon. Enter a directory path in the text field or click Browse to select a folder using the native file picker. Then click Scan Directory.

Archie will recursively scan the selected folder and all its subfolders. Code directories (node_modules, venv, .git, etc.) are automatically excluded to speed up scanning.

📊 Home Dashboard

After scanning, the Home page shows:

  • Stat Cards: Total files, folders, size, duplicate groups, and code files.
  • File Type Distribution: A doughnut chart showing the percentage of Documents, Code, Media, Archives, and Other files by size.
  • Top 10 Extensions by Size: Horizontal bar chart showing which file extensions occupy the most space.

Use the sidebar to navigate to Files, Duplicates, or Topics.

📄 Files View

The Files page lists all scanned files in a table. You can:

  • Search: Use the search box at the top to filter files by name or path in real time.
  • Filter by Type: Use the dropdown to show only Documents, Code, Media, Archives, or All.
  • Sort: Click any column header (Name, Type, Size, Modified) to sort ascending/descending.
  • Pagination: Navigate through pages if you have many files.
  • Actions: Right-click any file for options:
    • Open File: Opens the file with the default application.
    • Open Folder: Opens the folder containing the file.
    • Copy Path: Copies the full path to clipboard.
    • Rename: Rename the file directly.
    • Delete: Delete the file (with confirmation).

⚠️ Duplicates

Click Find Duplicates to scan for duplicate files. Archie compares files by size first, then by MD5 hash to confirm true duplicates.

Note: Cloud-only files (OneDrive placeholders) that can't be read are automatically skipped.

For each duplicate group, you can:

  • Open All: Open all copies at once.
  • Delete This Copy / Delete All: Remove duplicates safely.
  • Copy Paths: Copy all paths in the group.
  • Show in Explorer: Reveal the file in Windows Explorer.

🌳 Directory Tree

The left sidebar always shows the directory tree of the currently scanned folder. You can:

  • Expand/Collapse: Click the arrow ▶/▼ next to any folder.
  • Select: Click a folder or file to select it. The top bar path updates.
  • Double-click: Double-click a folder to scan it. Double-click a file to open it.
  • Right-click: Access the same actions as in the Files table.

🏷️ Topics

Archie automatically groups files by topic based on their folder names and paths. You can:

  • Search Topics: Use the search box to filter topics and their files.
  • Add Custom Topic: Click + Add Custom Topic to create a keyword-based topic. Any file whose name or path contains the keyword will appear under that topic.
  • Edit Topic: Double-click a topic title to rename it.
  • Delete Topic: Click the ✕ button on a topic card to remove it. This does not delete any files.

⚙️ General Tips

  • Scan Cache: Scans are cached for 10 minutes. Rescanning the same folder is instant unless you click Refresh.
  • Language: Use the dropdown in the top bar to switch between English and Italian.
  • Shortcuts: Press Enter in the path field to scan. Press Esc to close context menus.
  • Performance: Large folders with thousands of files may take a few seconds. Parallel scanning is used automatically.
